# Visual scene library — 14 distinct stages

- **Home / Command Deck — Mission Control Bridge:** ساحة قيادة KPI حقيقية ولوحة قرارات وشريط نشاط مستمر يفتح خدمة التنفيذ المالكة. Real interaction: نقاط حركة بين عناصر Command Deck حسب الأحداث الحقيقية.
- **Smart Scan — Scanning Radar:** رادار مسح للمجلد المخول مع مجموعات نتائج تتكون عند وصول دفعات الملفات. Real interaction: شعاع وقمم صغيرة تسير بنسب العمل المكتمل الفعلية لا Progress مصطنع.
- **Organization Studio — Organization Atelier:** سير ملفات مصنفة يتحول إلى قوائم Photos/Videos/Documents ثم خريطة Source-to-Destination قبل التطبيق. Real interaction: مكعبات مصغرة تنتقل إلى الفئة الصحيحة بعد قياس التصنيف، وتتوقف عند التعارض.
- **Google Workspace — Connected API Bridge:** بطاقات موارد الحساب المصرح به وخرائط طلبات API المستجيبة فعلا وصلاحيات OAuth المحددة. Real interaction: أنوار الربط لا تنشط قبل وصول API response حقيقي.
- **Applications — Software Dossier:** رف البرامج الحقيقية مع Publisher وSignature وVersion وحجم كل برنامج وخطة الإزالة/التحديث الدقيقة. Real interaction: بطاقة البرنامج تتحول إلى Verified Installed/Removed فقط بعد re-read فعلي.
- **Files / Instant Search — File Intelligence Chamber:** فهرس بحث فوري بجداول نتائج قابلة للاختيار ومفتش الملف ومعاينة المصدر والهدف. Real interaction: الصفوف والمصغرات تظهر مع دفعات الفهرس، ولا يحجب glow أسماء الملفات.
- **Storage Atlas — Capacity Topographic Map:** خريطة Treemap تتوسع مع قياس أحجام المجلدات الفعلية، مع تمييز المساحة الفارغة والقابلة للاسترداد. Real interaction: موجة تعبئة القطاعات فقط حسب عينات التحليل الفعلية.
- **Cleanup Vault — Safe Quarantine Lab:** شريط مرشحات التنظيف بميزان مخاطر وخريطة Before/After وخزنة استعادة. Real interaction: الملف ينتقل إلى Vault عند نجاح عملية Quarantine فقط.
- **Startup Control — Bootline Timeline:** سجل Autorun وScheduled Tasks وSCM مرتب على خط الإقلاع مع خطة تغيير حالة دقيقة. Real interaction: نبض حالة عنصر الإقلاع بعد إعادة قراءة Windows فقط.
- **System Observatory — Live Measurement Deck:** أجهزة قياس أصلية قابلة للحفر للعمليات والشبكة والعتاد، بوقت عينة وحد تغطية. Real interaction: Graph streaming حقيقي، وحساسات غير مدعومة تعرض Unavailable.
- **Repair Lab — Guided Rescue Sequence:** تسلسل تشخيص وإصلاح متدرج بملخص الأمر المعتمد ومخرجات runner الحقيقية. Real interaction: خطوات الإصلاح تضيء عند وصول stdout/stderr أو status من التنفيذ المعتمد.
- **Windows Services — SCM Dependency Galaxy:** شبكة علاقات الخدمة الأم والتابعة مع الحالة الفعلية ونافذة أثر إيقاف/تشغيل/تعديل. Real interaction: العقد تنبض مع re-read/SCM event وليس حركة منفصلة عن الواقع.
- **Automation Studio — Workflow Flight Deck:** محرر DAG مرئي يُظهِر Trigger→Queue→Worker→Receipt مع عرض Next Run حقيقي. Real interaction: العقد المتصلة تتحرك عند تلقي trigger أو worker event فقط.
- **Settings & Assistant — Preference & AI Lab:** معاينة مقارنة للإعدادات واللغة والثيم مع حدود واجهات AI وسجل أدواته المصرح بها. Real interaction: المعاينة تتغير فورًا لكن الحفظ لا يتم إلا بعد Apply.
