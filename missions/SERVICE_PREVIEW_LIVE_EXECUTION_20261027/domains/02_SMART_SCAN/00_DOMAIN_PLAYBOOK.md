# Smart Scan — LIVE DOMAIN PLAYBOOK

## مشهد هذا القسم
**Scanning Radar**: رادار مسح للمجلد المخول مع مجموعات نتائج تتكون عند وصول دفعات الملفات
**التفاعل:** شعاع وقمم صغيرة تسير بنسب العمل المكتمل الفعلية لا Progress مصطنع
**القرارات:** عناصر حقيقية مع المسارات ودرجة اكتمال النطاق
**سلسلة الأوامر الأصلية:** Select scan scope; Quick/Deep; inspect discoveries; cancel; route fix

## بناء الشاشات والمقياس
أبقِ مراجع DAY/NIGHT الأصلية وطبيعة القسم؛ أزرار العجلة وWorkbench تفتح كل خدمة بوسائلها الخاصة. الأحداث من Native/IPC فقط. لا تتجاوز نافذة التطبيق؛ القوائم تتدحرج داخليًا. كل إجراء يطلب تصريحًا عند أثره. Browser preview لا يعد إثبات Electron.
