# Organization Studio — LIVE DOMAIN PLAYBOOK

## مشهد هذا القسم
**Organization Atelier**: سير ملفات مصنفة يتحول إلى قوائم Photos/Videos/Documents ثم خريطة Source-to-Destination قبل التطبيق
**التفاعل:** مكعبات مصغرة تنتقل إلى الفئة الصحيحة بعد قياس التصنيف، وتتوقف عند التعارض
**القرارات:** التعارضات، المجلدات النهائية، البصمات وإمكانية الاستعادة
**سلسلة الأوامر الأصلية:** Choose source; design rules; build plan; approve move; journal; undo

## بناء الشاشات والمقياس
أبقِ مراجع DAY/NIGHT الأصلية وطبيعة القسم؛ أزرار العجلة وWorkbench تفتح كل خدمة بوسائلها الخاصة. الأحداث من Native/IPC فقط. لا تتجاوز نافذة التطبيق؛ القوائم تتدحرج داخليًا. كل إجراء يطلب تصريحًا عند أثره. Browser preview لا يعد إثبات Electron.
