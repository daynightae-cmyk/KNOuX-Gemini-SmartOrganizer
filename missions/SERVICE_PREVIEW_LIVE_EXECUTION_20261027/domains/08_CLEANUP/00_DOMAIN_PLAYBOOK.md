# Cleanup Vault — LIVE DOMAIN PLAYBOOK

## مشهد هذا القسم
**Safe Quarantine Lab**: شريط مرشحات التنظيف بميزان مخاطر وخريطة Before/After وخزنة استعادة
**التفاعل:** الملف ينتقل إلى Vault عند نجاح عملية Quarantine فقط
**القرارات:** الملفات المحمية ومجموع البايتات الفعلية وسجل الاستعادة
**سلسلة الأوامر الأصلية:** Scan; select candidates; review risk; quarantine; restore; verify reclaim

## بناء الشاشات والمقياس
أبقِ مراجع DAY/NIGHT الأصلية وطبيعة القسم؛ أزرار العجلة وWorkbench تفتح كل خدمة بوسائلها الخاصة. الأحداث من Native/IPC فقط. لا تتجاوز نافذة التطبيق؛ القوائم تتدحرج داخليًا. كل إجراء يطلب تصريحًا عند أثره. Browser preview لا يعد إثبات Electron.
