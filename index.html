KNOuX SmartOrganizer is a Windows desktop application for measuring system health, finding and classifying files, reviewing storage, and planning file organization. Sensitive actions remain subject to user review and approval.

How we handle dataExplore project

Development status: Google Workspace connectivity is not yet implemented in the reviewed preview. No Google account connection is implied by this website.

Files & Organization

Inspect authorized folders, search indexed files, explore file categories, and review proposed organization actions before execution.

Storage & Smart Scan

Explore measured storage usage and system diagnostics with clear distinctions between available evidence and unavailable information.

System & Automation

Review Windows system performance, startup evidence, and locally drafted automation workflows. Actual execution is separately controlled.

Optional Google integration

The project includes a Google Workspace preview. The initial planned connection uses Google sign-in (basic identity details) and read-only Google Sheets access, only after explicit user authorization. Other Workspace services are not connected in the reviewed development build.

We explain intended Google data use in our Privacy Policy. Read our Terms of Service before using a development build.
